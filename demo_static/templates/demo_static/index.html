Что здесь происходит

  • {% verbatim %}{% load static %}{% endverbatim %} — вверху шаблона включает тег static.
  • {% verbatim %}{% static 'demo_static/css/style.css' %}{% endverbatim %} превращается в реальный URL:
    {% static 'demo_static/css/style.css' %}
  • Картинка тоже из static:
    {% static 'demo_static/img/logo.svg' %}
