Демо тега {% verbatim %}{% for %}{% endverbatim %}

Слева (в файле) — код с комментариями {% verbatim %}{# ... #}{% endverbatim %}, справа (эта страница) — результат его работы. Комментарии {% verbatim %}{# #}{% endverbatim %} в браузер НЕ попадают.

{# ============================================================ ДЕМО 1. Обычный перебор списка + переменные forloop. Переменная lessons пришла из views.py (через context). На КАЖДЫЙ элемент списка Django повторяет одну строку . ============================================================ #}

1. Перебор + forloop

{% for lesson in lessons %} {# СТАРТ цикла: lesson = очередной словарь из списка #} {# номер витка, считая с 1 #} {# номер витка, считая с 0 #} {# номер витка с конца #} {# точка: lesson.title == lesson['title'] #} {% endfor %} {# КОНЕЦ цикла — {% templatetag openblock %} endfor {% templatetag closeblock %} обязателен #}
counter
(с 1)		 counter0
(с 0)		 revcounter
(с конца)		 title
(через точку)		 метки first / last
{{ forloop.counter }}{{ forloop.counter0 }}{{ forloop.revcounter }}{{ lesson.title }} {# forloop.first / forloop.last — True только на крайних витках #} {% if forloop.first %}первый{% endif %} {% if forloop.last %}последний{% endif %}
{# ============================================================ ДЕМО 2. {% templatetag openblock %} empty {% templatetag closeblock %} — что показать, если список ПУСТОЙ. empty_list = [] (из views.py), поэтому тело цикла ни разу не сработает, а выполнится ветка после {% templatetag openblock %} empty {% templatetag closeblock %}. ============================================================ #}

2. {% verbatim %}{% empty %}{% endverbatim %} на пустом списке

    {% for x in empty_list %}
  • {{ x }}
    • {% empty %}
  • Список пуст — сработала ветка {% verbatim %}{% empty %}{% endverbatim %}
    • {% endfor %}
